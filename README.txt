WELLFINDER NM • VERSION 3
Upload all files except this README to the root of a GitHub Pages repository or a static Netlify site. No build or secret key is required for the GIS queries. On iPhone, open the hosted URL in Safari, tap Share, then Add to Home Screen. A network connection is required for new lookups. Previously saved wells are stored locally and the app shell can be opened offline after the service worker caches it.

Search by partial well name or 10-digit API. Use the federal ownership filters only if you want to exclude unknown records. GIS coordinates are approximate surface hole locations. WGS84 geometry is requested; when absent, source coordinate attributes and their datum (if known) are shown. Check the latest C-102 for any surveying or directional use. Bottomhole and take-point coordinates are not automatically extracted. The app links to OCD details and document searches, not a verified federal APD. Federal ownership and APD approval field do not establish current BLM approval.

Sources: NM state well_sites GIS, December 2025 OCD data copy, November 2024 OCD GIS archive. The state GIS refresh date could not be established. The app searches up to 500 results per source and shows coverage warnings. Some records do not have API numbers or ownership fields. Source schemas were inspected, but live query execution and browser cross-origin behavior could not be tested in the development environment. The first hosted search should be treated as an integration test. The registered official OCD API is a potential next step for recent permits.

Shared-pad candidates: select Find shared-pad wells (30 ft chain). The app uses a fixed 30 ft maximum surface-hole-to-surface-hole connection, searches every newly discovered well, and stops when no new connected wells remain. There is no maximum distance from the starting well. All three sources are queried without name, county, operator, status or ownership filters. API numbers are used for deduplication when available. Only confirmed WGS84 coordinates are used; the first accepted coordinate per well is retained during traversal. CSV includes straight-line distance from the starting well, connection distance, linked well name/API, chain depth and starting-well flag. Failed or capped source queries are reported as possible incomplete coverage. Distances use an approximate great-circle calculation and GIS accuracy is not guaranteed. Confirm membership using the approved plat or imagery. Live spatial queries require a hosted browser integration test.
